REGRAS
- Tipo Movimentação == VIDA NOVA
- Data Inclusão Vida e Data Início Beneficiário convertidas para datetime
- Diferenca = Data Inclusão Vida - Data Início Beneficiário
- Descrição Status Atual Beneficiário == Ativado
- Descrição Status Atual Contrato == Aprovado
- Descrição Status Vida em:
  Ag.Ativação
  Aposentado / Demitido
  Ativo
  Em Análise
- Base válida: Diferenca <= 0
